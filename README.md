# Benchmark 02 — пакет для Claude · редакция 2

Основное задание: [BENCHMARK_02_CLAUDE.md](BENCHMARK_02_CLAUDE.md).

Обязательна веб-платформа. Стек, 2D/3D-представление, художественное решение и способы создания ассетов выбирает исполнитель. В `references/` — шесть ориентиров качества и настроения, со ссылками из соответствующих этапов. Персонаж и монстр представлены одним артом каждый; точное повторение дизайна не требуется.

Передай пакет Claude в рабочем проекте. Исходники предыдущего прототипа можно приложить как необязательную основу: исполнитель вправе их использовать, переработать или начать заново. Сам пакет содержит задание и референсы, а не исходный код игры и не готовые билды.

## Текст для запуска

> Выполни BENCHMARK_02_CLAUDE.md. Сам выбери подходящий веб-стек и способ получить сочный, привлекательный визуал; полноценное 3D допустимо, референсы не требуют точного повторения. Проходи пять этапов самостоятельно, без ожидания промежуточных согласований. Перед каждым переходом сохрани и проверь отдельный воспроизводимый билд этапа. Сохраняй заданную планку качества и небольшой игровой scope. При реальном блокере сохрани достигнутое, укажи невыполненное требование и причину остановки. В конце предоставь архивы этапов и короткий фактический отчёт.
