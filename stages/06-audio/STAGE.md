# Этап 06 — Звук (дополнительно к пяти этапам задания)

**Статус: DONE** (по проверке исполнителя)

## Что сделано (`src/audio/sound.ts`)
- **Процедурный звук на Web Audio API:** все звуки синтезируются кодом (шум + осцилляторы + фильтры + огибающие), без аудиофайлов — воспроизводимо и правится программно, как остальные ассеты.
- **Только render-сторона:** звук потребляет события симуляции (`shot`, `monster_hit`, `monster_killed`, `monster_spawn`, `monster_attack`, `player_hit`, `wave_*`, `victory`, `defeat`) и никогда не пишет в состояние игры.
- **Набор звуков:** выстрел (треск + низкий удар + металлический «зип», лёгкий разброс высоты); попадание в металл (рикошетный звон) и камень (хруст + осыпь); попадание по монстру (влажный удар + хитмаркер); смерть (падающий визг + бульканье + сигнал подтверждения убийства); рык при появлении из логова; взмах когтей при атаке; урон игроку (удар + хруст брони + предупреждающий гул); шаги по фактически пройденному пути; сирена начала волны, аккорд зачистки, победная арпеджио, тревожный аккорд поражения; фоновый эмбиент (ветер + низкий гул).
- **Пространство:** панорама по экранной горизонтали относительно игрока и затухание с расстоянием; общий компрессор против клиппинга при интенсивной стрельбе.
- **Управление:** `M` — вкл/выкл звука, `?mute=1` — запуск без звука. AudioContext создаётся при первом жесте пользователя (политика автозапуска браузеров).
- **Машинный доступ:** `__game.audio.info()` (счётчики сыгранных звуков, состояние контекста), `mute()`, `volume()`, `peak()` — пиковый уровень выхода (анализатор на мастер-шине) для проверки, что звук реально генерируется.
