# Этап 05 — Освещение

**Статус: DONE** (по проверке исполнителя)

## Что сделано (`src/render/lighting.ts`, `src/assets/drone.ts`)
- **Ночная sci-fi атмосфера:** почти чёрный фон, слабый холодный hemisphere + приглушённый IBL, холодный «лунный» направленный свет с мягкими тенями (4096²). Тон-маппинг ACES, bloom из этапа 04.
- **Локальные источники** (фиксированный набор из ~20 точечных, лёгкое мерцание): красные над бронещитами логов у каждых ворот, янтарные кольца колонн и фоновых корпусов, циановые полосы барьеров, красные лампы пилонов; эмиссивы флоры/ламп/монстров светятся через bloom.
- **Фонарь игрока:** прожектор с тенями (1024²) от дула по направлению прицела, угол = полуугол сектора видимости; лёгкий объёмный конус; плюс мягкий холодный свет ближнего радиуса. Визуально заменяет полупрозрачный веер этапа 01.
- **Световой дрон:** квадрокоптер (корпус, кольцо, роторы, навигационные огни) непрерывно облетает арену по замкнутому сплайну через тёмные участки (углы, руины, ворота), высота ~4.6 м с покачиванием; прожектор вниз с тенями (1024²) и раскачивающимся пятном + объёмный луч (аддитивный конус).
- **Боевые вспышки:** краткий свет выстрела и попаданий (пул из этапа 04) теперь заметно освещает окружение в темноте.
- **Независимость от видимости:** свет никак не влияет на геймплей; монстр рисуется (и отбрасывает тень) только если его разрешила система видимости.
- **Debug-оверлеи** (веер сектора, кольцо, подписи причин, панель) выключены в обычном режиме, включаются F3 / `?debug=1`.

## Проверки (фактически выполнены)
- **Повтор проверок этапа 01 на финальном билде:** реальные WASD (направления/нормализация/коллизии), реальная мышь по 8 целям (8/8), скрытие за укрытием с указанием `cover_e`, вне сектора, ближний круг, граница сектора, пиксели ID-прохода = видимость, удержание клавиш/ЛКМ в реальном времени, полный проход 3 волн; повторено после reload и после полного перезапуска браузера. Плюс проверки 02–04 (ракурсы, анимации, эффекты, независимость боя от FX).
- Debug выключен в обычном режиме; реальное нажатие F3 включает и выключает оверлеи.
- Дрон летит в реальном времени (позиции меняются каждые 0.4 с), маршрут покрывает арену.
- Проход дрона: 8.3% пикселей кадра заметно меняются между двумя позициями; яркость у укрытия `cover_a` в пятне 0.30 против 0.03 без него; тени от стен/укрытий двигаются; хэш геймплея совпадает с эталонным прогоном без дрона.
- **Свет ≠ видимость:** монстр позади игрока (вне сектора, вне ближнего радиуса) прямо под прожектором дрона (яркость места 0.33 против 0.03) — 0 пикселей, 0 изменённых пикселей кадра относительно сцены без него (нет ни силуэта, ни тени); после наведения прицела система видимости его раскрывает — 173 пикселя.
- Читаемость: при 4 фазах облёта видимые монстры имеют среднюю яркость пикселей ≥0.17 при средней яркости кадра 0.07, максимум ≥0.55.
- Вспышка выстрела: яркость вокруг стрелка 0.078 → 0.137 в кадр выстрела → 0.078 через 20 тиков.
- Производительность: 60 FPS (vsync) в headless Chrome на RTX 4090, ~2.7 мс CPU на кадр.

## Итерации
4 существенные: базовая световая схема; полностью чёрный кадр — NaN в шейдере объёмного луча (`pow` от отрицательной интерполированной uv при MSAA) размазывался bloom'ом, плюс фонарь внутри модели игрока затенял весь конус собственной головой; баланс яркости (пересвеченный монстр у фонаря, пересвеченное пятно дрона, слишком тёмный фон); заморозка времени света для детерминированных сравнений кадров. Время/токены — счётчиков нет, неизвестно.

## Ограничения
- Объёмные лучи — «фейковые» аддитивные конусы, без настоящего рассеяния.
- Тени точечных источников не отбрасываются (только луна, фонарь и дрон) — ради производительности.
- Проверено только на десктопном GPU (RTX 4090, ANGLE/D3D11) в Chrome; другие браузеры/GPU не проверялись.
