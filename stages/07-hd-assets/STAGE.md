# Этап 07 — HD-ассеты (игрок, монстр, environment kit) + слабая перспектива

**Статус: DONE** (по проверке исполнителя)

## Что сделано
- **Автономный machine-driven pipeline ассетов** (`assets-src/`, `npm run assets`): JSON-спецификация → headless **Blender 4.2 LTS** (Python) → процедурное hard-surface/органическое моделирование (bevel, subdivision с crease, lathe/shell-пластины, свипы рогов и клинков, displace-скалы) → общий UV-атлас → **запекание Cycles**: albedo (палитра × AO × износ кромок/сколы до металла × грязь × царапины × паттерны: hazard-полосы, панельные швы, решётки, заклёпки, органические прожилки), ORM (AO/шероховатость/металл), tangent-normal (скруглённые фаски + микрорельеф) → **GLB** (WebP-текстуры). Ручной работы нет; правка спецификации и повторный запуск дают согласованную модель со всех сторон. Сборщик `scripts/build-assets.mjs` хэширует входы (спека + скрипт + lib.py) и пересобирает только изменившееся; `scripts/get-blender.sh` ставит Blender локально.
- **HD-игрок** (~48k tris): тяжёлый штурмовик с многослойными наплечниками, шлемом с оранжевым визором, рюкзаком (варианты reactor/pack с трафаретной «6»), детальной винтовкой с красными катушками.
- **HD-монстр** (~26k tris): серебристый хитиновый панцирь, крупные загнутые красные рога, длинные ноги с когтями, клинки-косы, светящиеся швы и пасть.
- **Environment kit** (15 модулей, ~21k tris + бесшовный пол): 3 варианта стеновых модулей, баррикада + торцы, блок-ворота логова, 2 ящика, пилон с янтарным кольцом, 2 скалы, бочка, 3 светильника; пол — запечённый с high-poly на плоскость (selected-to-active) тайл 8×8 м + мировой макро-слой грязи и мокрых луж в шейдере.
- **Программная изменяемость сохранена:** HD-детали посажены на те же процедурные риги (каждая деталь — в локальном пространстве своего сустава), поэтому вся анимация/IK/хват/реакции/смерть работают без изменений; варианты снаряжения переключаются в рантайме, палитра перекрашивается в рантайме (тинт поверх запечённого износа), числа рига Blender ↔ TS проверяются юнит-тестом. Модули окружения масштабируются под игровые footprints — коллизии, видимость и выстрелы по-прежнему из симуляции.
- **Слабая перспектива:** `PerspectiveCamera` с тем же фиксированным азимутом/углом, без вращения, длиннофокусный объектив (85/135/200 мм экв., по умолчанию 135 мм ≈ 10° FOV) далеко от сцены; кадрирование подобрано так, что масштаб у игрока совпадает с изометрией.
- **Меню паузы** (Esc / P): Player Classic/HD, Monster Classic/HD, Environment Classic/HD kit, Camera Isometric/Weak perspective, Lens 85/135/200 мм. Настройки сохраняются в браузере; URL: `?hd=1`, `?player=hd`, `?monster=hd`, `?env=hd`, `?camera=persp`, `?focal=135`. По умолчанию — классика (как раньше). Машинный доступ: `__game.settings.get/set/menu/info`.

## Ограничения
- Проверено в headless Chromium с программным WebGL (SwiftShader, Linux) — производительность на реальных GPU не измерялась; Windows/GPU-прогон не делался.
- Модели «в лиге референсов» по оценке исполнителя по кадрам; человеческой приёмки нет. Референсы — painterly-концепт; игровые модели — PBR-ассеты при изометрическом масштабе.
- Сборка ассетов в релизном качестве (атлас 2048, 12–16 сэмплов) на 4 CPU занимает ~15–17 мин на персонажа; `--fast` — ~1 мин.
